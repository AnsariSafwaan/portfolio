# Safwaan Ansari - Full Stack Developer Portfolio 🚀

A modern, responsive, and high-performance portfolio website built with **React**, **Vite**, and **Tailwind CSS**. Designed to showcase full-stack projects, technical skills, development experience, and contact information with interactive micro-interactions.

---

## 🌟 Features

- **Hero Section**: Bio, animated greeting, interactive code snippet card, and direct contact buttons.
- **Value Highlights**: 4 key engineering philosophies (Clean Code, Modern Stack, Problem Solver, Continuous Learning).
- **About Me & Quick Info**: Background overview, workspace preview, and live availability status indicator.
- **Technical Skills**: Bento-style grid with official SVG technology logos and filtering.
- **Featured Projects**: Interactive mockup previews (Kanban, E-Commerce, Weather, Portfolio) with detailed modals and source/demo links.
- **Numbers Speak / Stats**: Highlighting key milestones and experience metrics.
- **Work Experience Timeline**: Vertical timeline detailing career progression and responsibilities.
- **Call-to-Action & Mountain Artwork**: Engaging contact section with custom landscape illustrations.
- **Curriculum Vitae (CV) Viewer**: Built-in resume modal with one-click print and PDF export.

---

## 🛠️ Tech Stack

- **Frontend Library:** React 19
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React & Custom SVGs
- **Animations / FX:** Canvas Confetti & CSS Transitions

---

## 🚀 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/safwaan-portfolio.git
   cd safwaan-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
